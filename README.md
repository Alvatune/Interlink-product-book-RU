# Interlink — русскоязычная продуктовая книга

Interlink — разрабатываемый фундамент для приложений, работающих с объектами, связями, историей и управляемыми изменениями. Основной проверочный домен — инженерные и производственные процессы; архитектура предусматривает развитие в другие отрасли и безопасную работу людей и агентов.

## Как устроена публикация

Авторские страницы находятся в [wiki](wiki). Каталог [book](book) — автоматически формируемая копия с обычными Markdown-ссылками: её можно читать непосредственно в GitHub, даже когда отдельная функция Wiki недоступна.

GitHub Wiki требует отдельной публикации в wiki-репозиторий. Наличие исходников в основной ветке не означает, что такая публикация уже выполнена. Порядок подготовки описан в [руководстве редактора](PUBLISHING.md).
